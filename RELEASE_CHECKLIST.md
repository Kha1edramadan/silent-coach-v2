# Release Checklist

Before treating a build as public product software:

- [ ] GitHub Actions build passes.
- [ ] Core self-test passes.
- [ ] APK installs on a real Android device.
- [ ] Onboarding completes.
- [ ] Arabic/English switching works and Arabic is RTL.
- [ ] Workout can add, remove, replace and reorder exercises.
- [ ] Sets/reps/weight/RPE/RIR/rest are saved correctly.
- [ ] Timed exercises work correctly.
- [ ] Previous performance appears correctly.
- [ ] Nutrition accepts gram weights and recalculates macros.
- [ ] Saved meals and custom foods work.
- [ ] Barcode import marks unverified records correctly.
- [ ] Historical nutrition entries do not change after food revisions.
- [ ] Weight and measurements persist after app restart.
- [ ] Quotes show attribution and source type.
- [ ] Quote and reminder notifications respect their settings.
- [ ] Backup export and restore work.
- [ ] No secrets are present in the repository.
