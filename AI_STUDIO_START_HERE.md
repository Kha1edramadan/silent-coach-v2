# AI Studio — Start Here

This repository contains an older Java implementation and a separate rebuild specification.

For Google AI Studio:
1. Import this repository.
2. Open `AI_STUDIO_MASTER_REBUILD.md`.
3. Treat `app/src/main/java/com/silentcoach/v2/` as legacy reference only.
4. Do not merge the legacy Java architecture into the new Kotlin/Compose implementation.
5. If the canonical `silent-coach-v2-food-ui.zip` source archive is available, use it as the starting codebase.
6. Execute the rebuild phases in the master prompt in order.

Master specification:
`AI_STUDIO_MASTER_REBUILD.md`

Rebuild branch:
`ai-studio-rebuild`
